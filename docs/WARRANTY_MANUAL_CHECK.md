# 保証書管理：Mac と iPhone での確認手順（はじめての人向け）

正本の仕様：[WARRANTY_MANAGEMENT_MVP_SPEC.md](WARRANTY_MANAGEMENT_MVP_SPEC.md)
実装の報告：[WARRANTY_MANAGEMENT_REPORT.md](WARRANTY_MANAGEMENT_REPORT.md)

順番に進めてください。うまくいかなかったところは、その番号と画面の様子（スクリーンショットや出てきた文）を教えてください。

---

## 1. 自動テスト（Mac の Xcode）

1. GitHub から最新版を ZIP でダウンロードして開きます（新しい番号のフォルダ）。
2. `LifeOS.xcodeproj` をダブルクリックして Xcode で開きます。
3. 上のほうの端末の選択で、iPhone のシミュレーター（例：iPhone 16）を選びます。
4. キーボードで **⌘（command）＋ U** を押します（全部のテストが動きます。数分かかります）。
5. 左の「◇（テスト）」のマークを押すと結果の一覧が見られます。
   - すべて緑のチェックなら成功です。テストは **207件**（これまでの169件＋保証書の38件）の予定です。
   - 灰色の「スキップ」が1件出ることがあります（「シミュレーターではファイル保護の状態を読めない」）。これは失敗ではありません。実機で 6-3 を確認します。
   - 赤い × があれば、そのテストの名前と、右に出ている文を教えてください。
6. 黄色い三角（警告）が出ていれば、その文も教えてください。

## 2. Free・Premium・Premium 終了後の3つの状態（シミュレーター）

### 2-1. Free（はじめて）

1. ▶（Run）でアプリを起動します。
2. プロフィール → 開発用設定 → プランを **Free** にします。
3. 「リスト」タブを開きます。いちばん上に「大切な書類　Premium」と「保証書」があることを確認します。
4. 「保証書」を押します。「保証書を、探さなくていい場所へ」という説明と「Premium を見る」ボタンが出ることを確認します。
   - 見本の保証書（冷蔵庫など）が出ないことも確認してください。

### 2-2. Premium

1. 開発用設定でプランを **Premium** にします。
2. 「リスト」→「保証書」を開きます。右上に「＋」が出ます。
3. 「＋」→「あとで追加」→ 製品名に「冷蔵庫」と入れて、右上の「保存」を押します。
   - 製品名だけで保存できることを確認します（読み取りに失敗したときも、手入力で保存できます）。
4. もう一度「＋」で、次の内容の保証書を作ります。
   - 製品名「洗濯機」
   - 購入日：今日の日付
   - 保証期間：1年
   - 紙の保管場所：「リビングの書類ケース、上から2段目」
   - 保証終了日に「購入日 2026/10/13 ＋ 1年」のような計算の根拠が出ることを確認します。
5. 一覧で「期限が近い」「保証期間中」「期限終了」「終了日 未入力」の順に分かれていることを確認します。
6. 上の検索欄に「書類ケース」と入れて、洗濯機だけが残ることを確認します。

### 2-3. Premium 終了後

1. 開発用設定でプランを **Free** に戻します。
2. 「リスト」→「保証書」を開きます。
   - 保存した保証書がそのまま見えること
   - 「Premium が終了しているため…」の案内が出ること
   - 右上の「＋」が無いこと
3. 保証書を開き、「編集」が無いこと・「書き出す」「削除」はあることを確認します。
4. 「書き出す」を押して共有の画面が出ることを確認します（「ファイルに保存」などを選べます）。
5. プランを Premium に戻すと、同じデータで編集できることを確認します。

## 3. 再起動しても残るか

1. 保証書を1件、写真つきで登録します（4 を参照）。
2. シミュレーターでアプリを完全に終了します（ホーム画面に戻って、上にスワイプして消す）。
3. Xcode の ▶ でもう一度起動します。
4. 保証書と写真が残っていることを確認します。

---

## 4. 写真の追加と文字の読み取り

### 4-1. 写真から選ぶ（シミュレーターでもできます）

1. 保証書の写真を Mac から入れます：写真ファイルをシミュレーターの画面にドラッグ＆ドロップすると「写真」アプリに入ります。
2. 「＋」→「写真から選ぶ」→ 保証書の写真を選びます。
3. 「この iPhone の中で文字を読み取っています…」のあと、「読み取り結果の確認」が出ます。
   - 「候補を反映」を押すまで、入力欄が変わらないこと
   - 「確認が必要」の印がある項目があること（日付が複数ある・読み取りが不確かなど）
   - 先に自分で製品名を入れていた場合は、「入力済みのため反映しません」と出て上書きされないこと
4. 「反映しない」を押した場合は、何も入らないことを確認します。
5. 同じ写真をもう一度追加すると「同じ写真があります」と出ることを確認します。
6. 写真を11枚以上は追加できないことを確認します（10枚まで）。

### 4-2. カメラで撮る（iPhone の実機）

シミュレーターではカメラを使えないため、「この端末ではカメラを使えません」と出れば正しい動きです。

実機で試すには、iPhone をケーブルで Mac につなぎ、Xcode の端末の選択で自分の iPhone を選んで ▶ を押します（はじめての場合は、Xcode の Signing & Capabilities で自分の Apple Account を選ぶ必要があります。うまくいかなければ教えてください）。

1. 「＋」→「カメラで撮る」→ はじめてのときに出るカメラの許可で「OK」を押します。
2. 日本語の保証書・レシート・製品ラベルをそれぞれ撮り、読み取り結果を確認します。
3. カメラを「許可しない」にした場合：設定アプリ → 生活OS → カメラ をオフにして、「カメラで撮る」を押します。「カメラの使用が許可されていません」と「設定を開く」が出て、アプリが止まらないことを確認します。
4. 写真へのアクセスを「制限付き」にしていても、「写真から選ぶ」で選んだ写真は追加できることを確認します（写真の選択画面はアプリの外で動くため、許可は不要です）。

### 4-3. 形式

HEIC（iPhone の写真）、JPEG、PNG をそれぞれ追加し、詳細画面で写真を押して大きく表示できることを確認します。

## 5. 通知（iPhone の実機がおすすめ）

1. 保証書を「保存」すると、はじめてのときに通知の許可が出ます。「許可」を押します。
2. 確かめやすいように、保証終了日を **「今日から31日後」** にして保存します。
   - 通知は「30日前・7日前・当日」の 9:00 です。31日後にすると、30日前の通知は「明日の 9:00」になります（過ぎた時刻の通知は予約しない決まりです）。
   - 実際に届くのを見るには、iPhone の設定 → 一般 → 日付と時刻 で「自動設定」をオフにし、明日の 8:59 に変えて1分待ちます。確認が終わったら、「自動設定」をオンに戻してください。
3. 通知の文が「○○の保証終了まであと30日です」になっていて、製造番号・保管場所が出ていないことを確認します。
4. プロフィール → 通知 →「保証書の期限」をオフにすると、通知が届かなくなることを確認します。
5. 保証書を削除すると、その通知も届かなくなることを確認します。

---

## 6. プライバシー

1. 機内モードにした状態でも、登録・文字の読み取り・閲覧・通知の予約ができることを確認します（外部へ通信しないため）。
2. 書き出しのとき「位置情報を除いて書き出す」「原本のまま書き出す」を選べることを確認します。
3. **端末のロック中に写真を読めないこと**（実機・パスコードの設定が必要）：
   - 保証書の詳細を開いたまま iPhone をロックし、10秒ほど待ってからロックを解除して、写真が表示されることを確認します。
   - 写真ファイルは「ロック中は読めない」設定で保存しています。ロック中にファイルの中身を直接確かめる方法は、ふだんの操作ではありません。この項目は「ロックを解除したあと、問題なく表示される」ことを確認してください。

---

## 7. 見やすさ

1. iPhone の設定 → アクセシビリティ → 画面表示とテキストサイズ → さらに大きな文字 で、いちばん大きな文字にして、一覧・詳細・登録の画面が読めるか確認します。
2. VoiceOver をオンにして、「保証書」「写真 1枚目を大きく表示」などが読み上げられるか確認します。
3. プロフィール → 表示設定 でダークモードにして、文字が見えにくいところが無いか確認します。
4. 「今日」画面：保証終了まで30日以内の保証書があるときだけ、「大切な書類」の小さな案内（落ち着いた金色の点）が出ることを確認します。
