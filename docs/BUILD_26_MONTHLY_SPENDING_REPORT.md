## 何を作ったか

1. **「お金」の画面の「月次レポート」のカード**（予算のカードの下・定期支出の上。今までの色・面に合わせた控えめなカード）
   - 対象の月・支出の合計（すべて／自分／共有の範囲で）・予算があれば残りの金額（自分だけ・わが家の共有を別々の行で）・いちばん多いカテゴリー（金額と％）・「詳しく見る」
2. **月次レポートの画面**（「詳しく見る」で開く。「閉じる」でお金の画面へ戻る）
   - 月の切り替え（前の月・次の月・今月に戻る）と「すべて／自分／共有」（お金の画面と同じ月・範囲を使う）
   - 支出の合計と件数
   - 予算と残り（**自分だけの予算と、わが家の共有予算は足さずに別々に**。予算を上回った月は「予算を 2,000円上回っています」と金額だけ）
   - 前月との差（下の「前月との差の決まり」）
   - 最近6か月の支出の推移（グラフと、月ごとの金額の一覧）
   - カテゴリー別の金額・割合・横棒（金額の多い順）
   - 「（月）の支出一覧を見る」
3. **最近6か月のグラフ**：Apple 純正の Swift Charts の縦棒（このアプリは iOS 17 からなので安全に使える。外部のライブラリは足していない）
   - 古い月から新しい月の順・6か月分・支出の無い月も 0円として並べる
   - 選んでいる月は濃い色にして、上に「表示中」の文字（色だけに頼らない）
   - 縦の軸は円の金額（「金額（円）」と表示）。見出しに「単位：円」
   - グラフをタップすると、その月のレポートへ。アニメーションは付けていない
   - グラフの下に、月・金額を文字で並べた一覧（VoiceOver で月と金額を読める。押すとその月へ）
   - 選んだ月が「今月までの最近6か月」の中なら、並びは今月までのまま（押しても並びが動かない）。それより前・先の月を選んだら、その月までの6か月
4. **カテゴリー別**：金額の多い順（同じ金額ならカテゴリーの決まった順）。各行にカテゴリー名・金額・％・横棒。VoiceOver は「食費、3,000円、支出全体の75パーセント」。**円グラフは使っていない**
   - 押すと、お金の画面の支出一覧を「その月・そのカテゴリー」で絞り込んで見せる（レポートを閉じて、一覧まで動かす）
5. **支出一覧の月の絞り込み**：月次レポートから開いたときだけ、一覧の上に「2026年10月の支出」と「月の絞り込みを外す」。カテゴリーは今までのカテゴリーのチップで外せる
   - 絞り込みは Build 23 の検索と同じ決まり（`ExpenseSearchFilter`：範囲・月・カテゴリー）を使う。検索欄は空に戻す

### 前月との差の決まり（評価・助言はしない）

- **今月**：前月の同じ日までと比べる（11月13日なら「11月1日〜13日」と「10月1日〜13日」）。前月にその日が無ければ前月の最終日まで（3月30日なら2月28日、うるう年は29日まで）
- **過ぎた月**：前月の月全体と比べる
- **先の月**：前月の月全体と比べる。ただし、その月に保存済みの支出が無ければ比べない
- 表示：「前月の同じ期間より 3,200円多い」「前月より 1,800円少ない」「前月と同じ金額」「比較できる支出がありません」（前月の期間に支出が無いとき）。比べた期間も文字で出す
- 良い・悪い・使いすぎ・節約できた などの評価や助言、予測は出さない

## 集計の決まり

- 支出の日付を、端末の暦（LifeCalendar：端末のタイムゾーン）の暦月で数える
- 同じ支出（同じ UUID）は1回だけ（「すべて」で、同じ支出が端末とわが家の両方にあっても1回）
- 「自分」は端末の自分だけの支出だけ、「共有」は Firestore から受け取った共有の支出だけ、「すべて」は両方を1回ずつ
- 消した支出は入らない（一覧から消えた支出は数えない）
- 月の金額は支出本体の金額（商品明細の合計は足さない）
- 定期支出の候補（未確認・今月は追加しない）は入れない。「今月分を追加」で保存した支出だけが入る
- 先の月は、保存済みの支出があるときだけ金額を出す（無ければ「まだ支出はありません」「記録なし」）。過ぎた月・今月で支出が無ければ 0円
- 金額は丸めない・推測しない。割合の％は整数で出し、全部のカテゴリーで足すと100になるようにする（端数の大きい順に1ずつ足す）。0円の月は割合を出さない（0 で割らない）
- 支出を1回だけ見て、6か月の推移・前月との差・カテゴリーをまとめて数える（支出が1,000件以上でも同じ支出を2回見ない）。画面では1回の描画で1回だけ作る

## 実機確認手順

1. 「お金」→ 予算のカードの下に「月次レポート」。月・合計・（予算があれば）残り・いちばん多いカテゴリーが出る
2. 「詳しく見る」→ 合計・予算と残り・前月との差・最近6か月・カテゴリー別が出る。「閉じる」でお金の画面に戻る
3. 「すべて／自分／共有」を切り替える → 合計・カテゴリーが範囲どおりに変わる。「すべて」の予算は自分だけ・わが家の共有の2行で、足した金額は出ない
4. 前の月・次の月・今月に戻る。グラフの棒・月の一覧を押すと、その月になる
5. 今月の「前月との差」が「前月の同じ期間より…」、過ぎた月は「前月より…」になる
6. カテゴリーを押す → レポートが閉じ、支出一覧がその月・そのカテゴリーだけになる。「月の絞り込みを外す」・カテゴリーの「すべて」で元に戻る
7. VoiceOver：合計・前月との差・グラフの棒・月の一覧・カテゴリーの行が、月・金額・カテゴリー・割合で読まれる
8. 支出が1件も無い状態（新しい端末・わが家に参加していない）でも落ちない。カテゴリー別は「（月）の支出はありません」、前月との差は「比較できる支出がありません」

## 既知の制限

- 推移は月ごとの合計だけ（カテゴリーごとの推移・週ごとは無い）
- 比べるのは前月だけ（前年の同じ月とは比べない）
- 月次レポートの月とお金の画面の月は同じ（レポートで月を変えると、お金の画面の月も変わる）
- 支出一覧の月の絞り込みは、月次レポートから開いたときだけ付く（お金の画面から直接は選べない）
- 先の月は、保存済みの支出があるときだけ金額を出す
- 評価・助言・予測はしない（事実だけ）

- グラフのタップは、棒のある位置の月を選ぶ（とても狭い画面では押しにくいことがあるため、下の月の一覧からも選べる）
