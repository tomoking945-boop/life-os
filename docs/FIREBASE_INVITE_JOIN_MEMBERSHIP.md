# わが家の作成・招待・参加

作業用ブランチ：`firebase-invite-join-membership`（main `90491a7` から作成。**main にはまだ入れていない**）

**Firebase（Firestore・Functions・Hosting）へは何も送っていない。Firebase Console・Apple Developer の画面も変えていない。**

## 何を作ったか

予定や家計簿などを同期する前の、**安全な共有の入口** です。

- 「わが家」の作成（名前と共有する種類を選ぶ）
- パートナーへの招待リンクの発行・共有・取り消し
- 招待の内容の確認（Preview）と、「参加する」を押したときだけの参加
- メンバーの表示（あなた／パートナー・参加待ち）

**予定・ToDo・家事・買い物・家計簿・保証書・メモなどの生活データは、まだ Firestore に送りません。**

## 決まりごと（仕様）

| 項目 | 内容 |
| --- | --- |
| わが家の数 | 1人が参加できるのは1つ |
| 人数 | 最大2人（オーナー＋パートナー） |
| 招待を作る・取り消す | オーナーだけ |
| 招待の期限 | 24時間・1回だけ |
| 新しい招待 | 前の未使用の招待は使えなくなる（取り消し） |
| 参加 | リンクを開いただけでは参加しない。招待の内容を見て「参加する」を押したときだけ |
| サインイン | 参加の前に Appleでサインインが必要（押したときだけ始める） |
| 自分の招待 | 自分で作った招待には参加できない |
| 参加できない招待 | 満員・期限切れ・使用済み・取り消し済み |
| 同じ参加が2回届く | 1回だけ成立（メンバーは増えない） |
| 表示・ログ | Firebase の UID・招待トークンを画面・ログ・分析に出さない |

### 共有する種類

わが家を作るときに選びます。**選んだ種類は「これからこの種類の共有の場所を使う」という設定で、いま iPhone にあるデータを送る意味ではありません。**

| 画面の名前 | 保存する値 |
| --- | --- |
| 予定 | `event` |
| ToDo | `todo` |
| 家事 | `chore` |
| 買い物 | `shopping` |
| 家計簿 | `money` |
| 保証書 | `warranty` |
| リスト・メモ | `list` |

- はじめは「ToDo」と「買い物」を選んだ状態。1つ以上選ばないと作れない
- 値は英語の固定の値で、アプリは `SharedSpaceKind`（`LifeOS/Core/Sharing/HouseholdModels.swift`）、サーバーは `SHARED_SPACE_KINDS`（`firebase/functions/src/household.js`）の1か所ずつで決めている（テストで同じことを確かめる）。予定・ToDo・家事・買い物は、共有項目（items）の種類と同じ値
- 決まった値以外・重複・空・8つ以上は、サーバーが断る。保存するときは決まった並びにそろえる
- 参加の前の確認画面には、選ばれている種類をすべて表示する
- 参加したあとは見るだけ。変更はまだできない（家計簿や保証書をあとから足すときは相手の確認が必要になるため、次の段階）

## データの形（Firestore）

```text
groups/{groupID}                  わが家
  name            わが家の名前（1〜50文字）
  createdBy       作った人の UID（作成の記録。変えない）
  createdAt / updatedAt
  sharedKinds     共有する種類（例：["todo", "shopping"]）

groups/{groupID}/members/{uid}    メンバー
  uid             文書 ID と同じ本人の UID
  role            owner | member
  joinedAt
  displayName     「メンバー」（Apple の名前は使わない）

memberships/{uid}                 1人1つのわが家の記録（新規。サーバーだけが読み書き）
  groupID
  joinedAt

invites/{tokenHash}               招待（文書 ID はトークンの SHA-256。トークンそのものは保存しない）
  groupID
  createdBy
  createdAt / expiresAt
  usedAt / usedBy
  revokedAt       （新規）取り消した時刻。未取り消しは null
```

- これまでの `groups`・`members`・`invites` をそのまま使い、別の仕組みは作っていない（招待の Function も、これまでの `createInvite`・`acceptInvite` を作り直した）
- `memberships/{uid}` は「1人1つ」を速く・確実に確かめるための記録。念のため、メンバー文書の `uid` でも探す（記録が無い古いデータや途中の状態にも対応）。グループの文書と本人のメンバー文書の両方が在るものだけを「参加中」とする
- **これまでのデータの移し替えは不要**：本番の Firestore にはまだ何も無い（ルールも全拒否のまま）

## サーバー（Cloud Functions）と権限

すべて **App Check 必須（`enforceAppCheck: true`）＋サインイン必須**。人数・1人1つ・招待の使用済み／取り消しは、**Functions のトランザクション**（まとめて一度に確かめて書く仕組み）で守る。

| Function | できる人 | すること |
| --- | --- | --- |
| `createHousehold` | わが家に参加していない人 | わが家・オーナーのメンバー・共有する種類・memberships をまとめて一度に作る |
| `getMyHousehold` | サインインした人 | 自分のわが家（名前・共有する種類・メンバーの役割と「自分か」・オーナーには有効な招待の期限）。**UID は返さない** |
| `createInvite` | オーナーだけ・2人未満のとき | 前の未使用の招待を取り消し、24時間・1回だけの招待を作る。返すのはリンクと期限だけ |
| `revokeInvite` | オーナーだけ | 未使用の招待を取り消す |
| `getInvitePreview` | サインインした人 | **参加はしない・何も書かない**。グループ名・共有する種類・期限だけを返す（招待した人の UID・メール・名前は返さない） |
| `acceptInvite` | サインインした人 | トランザクションの中で、期限・未使用・取り消し・人数・自分の所属を確かめ直し、パートナーのメンバー・memberships・招待の使用済みをまとめて一度に書く。同じ人の2回目は何も書かずに成功 |

- エラーのときアプリへ返すのは、決まった理由（`details.reason`：`expired`・`already-used`・`revoked`・`own-invite`・`household-full`・`already-in-household`・`not-owner` など）だけ。Firebase の生のエラー文・UID・トークンは返さない
- ログに出すのは、思わぬエラーのときの「Function の名前とエラーの種類」だけ（UID・トークンは出さない）
- 処理の本体：`firebase/functions/src/householdStore.js`（Firestore の読み書き）、`src/household.js`（決まりごと）、`src/invites.js`（招待の確かめ方）
- Node は 22 のまま

### Firestore のルール（`firestore.rules`）

| 内容 | ルール |
| --- | --- |
| サインアウト中 | すべて拒否 |
| メンバーでない人 | グループ・メンバーを読めない |
| わが家の作成・メンバーの追加 | **アプリからは誰もできない**（2026-10-22 に変更。これまでは「自分を owner にする同じ書き込み」でアプリから作れた）。作成・追加は Functions だけ |
| owner への昇格 | できない（メンバーの更新は拒否） |
| 人数の上限 | アプリからメンバーを足せないので、回り道できない |
| 共有する種類 | アプリから変えられない（グループで変えられるのは名前だけ） |
| 招待・memberships | アプリから読み書きできない |
| 他人の利用者情報・端末 | 読み書きできない |
| 退出 | 自分のメンバー文書だけ消せる（これまでどおり） |

## 外部へ送る情報

今回 Firebase へ送る（保存される）のは次だけです。

- Firebase Authentication の UID（Appleでサインインしたときに Firebase が作る番号）
- わが家の名前
- 選んだ共有する種類
- メンバーの記録と役割（owner／member）
- 招待の安全な識別情報（トークンの SHA-256 のハッシュ）
- 作成・期限・使用・取り消しの時刻

**送らないもの**：予定、ToDo、家事、買い物、家計簿、保証書、メモ、写真・PDF、端末の中にある既存のデータ、Apple のメールアドレスや名前。

招待のリンク（トークン入り）は、オーナーが「共有」を押したときに、iPhone の共有シートで本人が選んだ相手へ送られます。アプリの画面にリンクの文字は出さず、アプリを開いているあいだのメモリだけで持ちます（保存しない）。

## 画面の流れ

場所はこれまでの **プロフィール →「共有用アカウント」**。

1. サインインしていない：これまでどおり「Appleでサインイン」
2. サインイン済み・わが家なし：「わが家を作る」（招待リンクを開いていれば「招待内容を確認」も）
3. **わが家を作る画面**：名前（はじめは「わが家」）、共有する種類のチェック、「個人データは送信されません」の説明、「わが家を作る」（種類が0のときは押せない）
4. **作ったあと**：
   - メンバー：「あなた（オーナー）」と「パートナー：参加待ち」（参加後は「パートナー」）
   - 共有する種類
   - 「パートナーを招待」→ 期限（例：10月23日 18:30まで）と「共有」「招待を取り消す」
   - アプリを開き直したなどでリンクが手元に無い有効な招待は、期限と「新しい招待を作る」「招待を取り消す」（リンクは保存していないため、送り直すときは作り直す）
   - UID（アカウントの番号）は表示しない（これまで出していた「アカウントの番号：abcd…wxyz」もやめた）
5. **招待リンクを開いた人**：
   1. 「わが家への招待を受け取りました」→「招待を確認」「あとで」
   2. サインインしていなければ「参加するにはAppleでサインインしてください」。**押したときだけ** サインインを始める。やめたら参加しない（招待はメモリに残る）
   3. サインインできたら、もう一度招待の内容を読む：「○○への招待」、共有される種類、「現在iPhoneにある個人データは共有されません」、期限、「参加する」「やめる」
   4. 「参加する」で参加 → メンバーの画面と「わが家に参加しました」。招待はメモリから捨てる
   5. 「やめる」「あとで」・閉じる：何も変えず、招待を捨てる

## エラーのときの動き

| 状態 | 画面の文言（要旨） |
| --- | --- |
| 通信できない | 通信できませんでした。電波のよい場所で、もう一度お試しください |
| 招待の期限切れ | この招待は期限（24時間）が切れています |
| 使用済み・取り消し済み | この招待は使用済みか、取り消されています |
| 満員 | このわが家は満員です（2人まで） |
| 別のわが家に参加中 | すでに別のわが家に参加しています |
| 自分の招待 | 自分で作った招待には参加できません |
| Firebase 未接続・Function がまだ公開されていない | いまは共有の機能に接続できません。ほかの機能はこれまでどおり使えます |
| 処理中 | 「わが家を作っています…」「招待を作っています…」「参加しています…」など |

内部のエラー・UID・トークン・Firebase の生のエラー文は表示しません。
**Firebase に接続できなくても、今日・カレンダー・ToDo・保証書など、ほかの機能はこれまでどおり使えます。**

注意：Functions はまだ本番に deploy していないので、**いまの本番のアプリ（Xcode から入れた版）で「共有用アカウント」を開くと、わが家の欄は「いまは共有の機能に接続できません」になります**（正しい動き）。
