# 生活OS v2 仕様：ちゃんと管理しなくていい生活OS（Editorial Living）

> 2026-10-02 に受け取った改修指示の原文です。実装の進み具合と解釈は [IMPLEMENTATION_NOTES.md](IMPLEMENTATION_NOTES.md) を参照してください。

あなたは life-os リポジトリの実装担当です。

既存の生活OS UIプロトタイプをベースに、今回新たに決定したコンセプト・機能・デザインを反映してください。

最初に必ず以下を確認してください。

* README.md
* docs/LIFE_OS_UI_PROTOTYPE_IMPLEMENTATION.md
* docs/IMPLEMENTATION_NOTES.md
* 現在のSwiftUIコード
* DesignSystem
* AppState
* LifeStore
* 各FeatureのView / ViewModel

既存実装を理解する前に大規模変更しないでください。

今回は、Firebase / OpenAI API / StoreKit / AdMob等の外部サービスにはまだ接続しません。

まずはMockデータとローカル保存を使い、UI・UX・画面遷移・新機能の操作感を完成させてください。

⸻

今回の大きな目的

生活OSを、

「多機能な生活管理アプリ」

ではなく、

ちゃんと管理しなくても、暮らしが自然に整うアプリ

へ進化させます。

基本思想は以下です。

* 入力を最小限にする
* 整理はアプリ側が助ける
* 今日必要なことだけ見せる
* 失敗・未完了を責めない
* 放置しても復帰しやすい
* 一人でも価値がある
* 家族・パートナーと使うとさらに便利になる
* 表側はシンプルでも、見た目は上質でおしゃれ
* 機能を詰め込みすぎて見せない

⸻

新しいブランドコンセプト

以下を生活OSの中核コンセプトとして扱ってください。

「ちゃんと管理しなくていい。入れるだけで、暮らしが整う。」

一人で使う場合：

自分専用の生活秘書

家族・パートナーと使う場合：

家族の暮らしをまとめる共有OS

1. 新機能：おまかせInbox

「なんでも追加」に新しく、

とりあえず保存

を追加してください。

ユーザーは分類・日時・担当などを設定せず、思いついた内容だけ保存できます。

例：

「明日牛乳買う」

↓

Inboxへ保存。

Inboxでは、まだ正式分類されていない生活メモとして扱ってください。

初期Mock例：

* 明日牛乳買う
* 妻と旅行相談
* 電気代を払う
* 美容院を予約する

Inbox画面を新規作成してください。

画面名：

Inbox

表示：

* 未整理件数
* 入力内容
* AI分類候補風のMock表示
* 「まとめて整理」

今回はAI APIは使いません。

固定ロジックまたはMock分類で構いません。

3. 新機能：「今日これだけ」

Today画面を改修します。

大量のタスクを並べるのではなく、

今日優先して見る項目を最大3件程度

目立つ位置に表示してください。

表示名：

今日これだけ

例：

□ ゴミを出す
□ 歯医者 10:30
□ 牛乳を買う

残りがある場合：

「あと7件」

のように折りたたんでください。

残りをタップすれば一覧表示できます。

選定ロジックは今回Mockで構いません。

将来は、

* 期限
* 時刻
* 担当
* 優先度
* 暮らしメモリー
* ユーザーの余力

などを使う想定です。

4. 新機能：未完了救済

未完了タスクを赤字で責めるUIは使わないでください。

前日以前に残ったものがある場合、

Today画面に、

昨日残ったもの

として表示してください。

選択肢：

* 今日に表示
* 今週に回す
* あとで
* もうやらない

元の日付を勝手に削除・改変する設計にはしないでください。

今回はMock状態で再表示先を変える程度で構いません。

6. 新機能：暮らしメモリー

一人利用で特に重要な機能です。

生活OSが、

生活の周期や忘れやすいことを覚えておく

という体験を作ります。

新しいFeatureとして、

LifeMemory

または適切な命名で実装してください。

Mock例：

* シャンプー：前回購入から7週間
* 歯医者：前回から6か月
* エアコンフィルター掃除：前回から2か月
* 家賃：毎月27日
* ゴミ：火曜・金曜

Today画面では、

暮らしメモリー

セクションとして表示。

例：

シャンプー
そろそろ買う頃です

[買い物に追加]

別例：

エアコンフィルター掃除
前回から2か月です

[土曜日に追加]
[今回はスキップ]

今回はMockデータで実装してください。
