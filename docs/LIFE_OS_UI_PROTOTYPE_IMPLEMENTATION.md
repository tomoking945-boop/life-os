# 生活OS UIプロトタイプ実装指示

生活OSのiPhone向けUIプロトタイプをSwiftUIで実装してください。

今回はFirebase、OpenAI API、StoreKit、AdMobなどの外部サービスにはまだ接続しません。

目的は、実際にiPhone Simulatorで画面遷移と操作感を確認できるMockアプリを完成させることです。

## デザイン

全体をシックで高級感のあるデザインにしてください。

イメージは、Apple、MUJI、高級ホテルのデジタルサービスを組み合わせたような方向性です。

### カラーパレット

| 用途 | 色 |
| --- | --- |
| background | `#F6F4EF` |
| surface | `#FFFFFF` |
| primary | `#223C34` |
| text | `#222522` |
| secondaryText | `#747871` |
| accent | `#AD8A65` |
| divider | `#E6E1D8` |

- 大きな余白を取る
- カードは大きめの角丸にする
- 影はかなり弱くする
- 派手な原色や強いグラデーションは使わない

## DesignSystem

以下をDesignSystemとして部品化してください。

- Colors
- Typography
- Spacing
- CornerRadius
- Shadow

さらに共通Componentとして、以下を用意してください。

- LifeCard
- LifeButton
- LifeSectionTitle
- LifeAvatar
- LifeSegmentControl
- LifeTaskRow
- LifeMoneyRow
- LifeEmptyState

各画面に色、余白、角丸を大量に直接ハードコードしないでください。

## Free / Premium

MockでFree / Premiumを切り替えられる開発用スイッチを設定画面に用意してください。

## コード構造

MVVMを基本とし、以下の構造を作成してください。

```text
LifeOS
├─ App
├─ Core
│  ├─ Models
│  ├─ Extensions
│  └─ Utilities
├─ DesignSystem
│  ├─ Colors
│  ├─ Typography
│  ├─ Spacing
│  └─ Components
├─ Features
│  ├─ Today
│  ├─ Calendar
│  ├─ Tasks
│  ├─ Lists
│  ├─ Money
│  ├─ QuickAdd
│  ├─ Profile
│  └─ Premium
└─ Mock
   └─ MockData
```

## 実装条件

- 既存仕様を勝手に変更しないこと
- 既存ファイルがある場合は内容を確認してから実装すること
- いきなり大規模変更をしないこと
- 不明な仕様は勝手に補完せずTODOコメントにすること
- 外部サービスは接続しないこと
- ビルドエラーを残さないこと
- iPhone Simulatorで画面遷移を確認できる状態にすること
- Dynamic TypeやVoiceOverなど基本的なアクセシビリティも意識すること
